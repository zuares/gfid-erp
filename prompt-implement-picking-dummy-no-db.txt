1. Scan Item

   - belum ditempel ke nomor pesanan.
   - data cukup disimpan di JavaScript array/local state dulu.

2. Scan Pesanan
   - operator scan semua nomor pesanan / resi.
   - hasil scan masuk ke order pool.
   - data cukup dummy/local state dulu.

3. Mapping
   - sistem dummy mencocokkan item pool dengan order pool.
   - exact match jadi status Locked.
   - item beda/kurang masuk status Hold.

4. Replacement
   - jika item beda, stok kurang, atau item diganti, tampilkan di tab Replacement.
   - supervisor bisa klik Approve Replacement.
   - approval cukup ubah state di JavaScript dulu, jangan simpan database.

5. Kirim
   - hanya order status Locked yang muncul sebagai siap kirim.
   - tombol Proses Kirim cukup dummy alert/console log dulu.
   - jangan potong stok.
   - jangan confirm fulfillment asli dulu.
