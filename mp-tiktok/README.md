# MP-TikTok

Project frontend standalone untuk Pricing & ROAS Calculator.

## Menjalankan

Dari folder ini:

```bash
npm install
npm run dev
```

Buka URL localhost yang ditampilkan Vite.

## Build production

```bash
npm run build
npm run preview
```

Hasil production berada di folder `dist/` dan dapat di-host sebagai static files. Tidak ada Laravel, PHP, database, atau API yang diperlukan.
